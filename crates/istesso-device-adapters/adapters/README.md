# アダプター

機器 1 種類につき、ディレクトリを 1 つ置きます。ビルドのときに、ここにあるディレクトリから一覧を作るので、ほかのファイルには、アダプターの名前を書く場所がありません（[ADR 0012](../../../docs/adr/0012-device-framework.md)）。

| 置くもの | 内容 |
|---|---|
| `<名前>/adapter.rs` | 機器との会話。`pub fn entry() -> AdapterEntry` を持つ |
| `<名前>/recordings/*.rec` | 機器とのやり取りの記録。`cargo test` が、機器なしで再生する |

- ディレクトリの名前は、小文字の英字、数字、`_` で書きます。
- アダプターが使えるのは、`istesso_device_api`、`core`、`alloc` だけです。アダプターのクレートは、標準ライブラリを持たず、口のクレートにしか依存しません。ファイル、ネットワーク、プロセス、フレームワークの中身、ほかのクレートは、コンパイラーが通しません。
- アダプターが名乗っていないレポートは、機器に届きません。
- **アダプターは、本体と一緒にコンパイルされるコードで、本体のほかの部分と同じに信頼されます。** `cargo test` がソースの中の言葉を調べますが、それは確認を助けるためのもので、砂場ではありません。

**いまは、外からの機器のプルリクエストを受け付けていません。** 口（`istesso-device-api`）を、まだ固めていないためです。ひな形と手順書は、固めるときに置きます。
