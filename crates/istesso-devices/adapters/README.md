# アダプター

機器 1 種類につき、ディレクトリを 1 つ置きます。ビルドのときに、ここにあるディレクトリから一覧を作るので、本体には、アダプターの名前を書く場所がありません（[ADR 0012](../../../docs/adr/0012-device-framework.md)）。

| 置くもの | 内容 |
|---|---|
| `<名前>/adapter.rs` | 機器との会話。`istesso_device_api` だけを使う。`pub fn entry() -> AdapterEntry` を持つ |
| `<名前>/recordings/*.rec` | 機器とのやり取りの記録。`cargo test` が、機器なしで再生する |

- ディレクトリの名前は、小文字の英字、数字、`_` で書きます。
- アダプターは、標準ライブラリのファイル、ネットワーク、プロセスに触れません。`cargo test` が、ソースを調べて止めます。
- アダプターが名乗っていないレポートは、機器に届きません。

**いまは、外からの機器のプルリクエストを受け付けていません。** 口（`istesso-device-api`）を、まだ固めていないためです。ひな形と手順書は、固めるときに置きます。
