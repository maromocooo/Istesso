# ADR 0005：オーディオは独立した常駐サービスにする

- 状態：採用
- 日付：2026-11-15

## 背景

音を聴きながら作業できることは必須要件。音を映像の配信に付属させると、窓を閉じたり端末を替えたりするたびに止まる。

## 決定

- 音は、映像のセッションから独立した常駐サービスが扱う。
- 「音の出口」を1つ選ぶ。出力先の一覧には全ホストの機器を並べる。
- 各ホストの音を取り込み、非圧縮のまま出口のホストへ送って再生する。
- 長時間の再生で必要になる、時計のずれ補正と欠落の補完を行う。
- 再生中はそのホストを眠らせない。
- オーディオ機器を USB ごと別の PC に付け替えることはしない。

## 手を入れない経路

DAC が挿さっている PC でプレーヤーやブラウザを動かす場合、音は OS の標準経路でそのまま鳴る。この経路にはプロダクトが介入しない。音質を最優先する再生はこの経路で行う。

配信経路は、時計のずれ補正にリサンプリングを使うため、ビットパーフェクトにはならない。

## 部品

| 役割 | 部品 |
|---|---|
| 配信（ずれ補正、欠落の補完） | Roc Toolkit（MPL-2.0。条件つきで採用） |
| Linux の取り込みと再生 | PipeWire（Roc 用のモジュールあり） |
| Mac の取り込み | Core Audio のタップ（macOS 14.2 以降。仮想ドライバー不要） |
| Mac の再生 | Core Audio |

## 受け入れ条件

- 別のホストで再生した音楽が、選んだ出口から8時間途切れずに鳴る。
- 窓を閉じても、操作する端末を替えても止まらない。
- ローカル再生の経路の音が、導入の前後で変わらない。
