# ADR 0024：試用版の近道が使うローカルネットワークの許可

- 状態：試用版で採用
- 日付：2026-11-19

## 背景

Spotlight や Dock から開くと、入力の中継を起動するのはターミナルの外にあるアプリです。中継はペアリング済みのホストへ LAN でつなぐため、起動元にローカルネットワークの許可が要ります。

## 決めたこと

毎日の試用版では、起動元を `Istesso Dev Open` にそろえます。各アプリの近道は決まった URL を開くだけです。受付役は作成時の一覧にある URL だけを受け付け、同じチェックアウトの `daily.sh` に決まった引数を渡します。これで持ち主が近道のために許可を出す相手は 1 つになります。

## URL だけでは持ち主のクリックを確かめられない

どのプログラムも、受付役に URL を渡して、一覧のアプリを開けます。ウェブページも、ブラウザーで開くことを許すと、同じ URL を渡せます。受付役には、持ち主が近道をクリックしたかどうか分かりません。

Safari、Notes、Finder、Preview、Dia には持ち主の内容が映ります。`desktop` は画面全体を映します。この 6 つは近道を作るときに断り、受付役でも起動前に断ります。AURA に映すときも同じです。このチェックアウトには `daily-mac.sh` がないため、試用版ではこの 6 つの名前を固定します。近道と受付役は `DAILY_OWNER` と `DAILY_OPEN_HANDLER` を引き継ぎません。持ち主は自分のターミナルで `DAILY_OWNER=1` を付けて開きます。

将来、近道からも開けるようにするなら、受付役の窓にアプリ名と表示先を出し、持ち主に確認を求める方法があります。その場で OS の本人確認を受け、持ち主が選んだ起動を 1 回だけ許します。
