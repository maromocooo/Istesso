# ADR 0024：試用版の近道が使うローカルネットワークの許可

- 状態：試用版で採用
- 日付：2026-11-19

## 背景

Spotlight や Dock から開くと、入力の中継を起動するのはターミナルの外にあるアプリです。中継はペアリング済みのホストへ LAN でつなぐため、起動元にローカルネットワークの許可が要ります。

## 決めたこと

通常の近道では、起動元を `Istesso Dev Open` にそろえます。各アプリの近道は決まった URL を開きます。受付役は作成時の一覧にある URL だけを受け付け、同じチェックアウトの `daily.sh` に決まった引数を渡します。通常の近道のために許可を出す相手は 1 つです。

## URL だけでは持ち主のクリックを確かめられない

どのプログラムも、受付役に URL を渡して、一覧のアプリを開けます。ウェブページも、ブラウザーで開くことを許すと、同じ URL を渡せます。受付役には、持ち主が近道をクリックしたかどうか分かりません。

Safari、Notes、Finder、Preview、Dia には持ち主の内容が映ります。`desktop` は画面全体を映します。この 6 つに URL は割り当てません。古い一覧に URL が残っていても受付役が断ります。AURA に映すときも同じです。URL を開く近道と受付役は、子に `DAILY_OWNER` と `DAILY_OPEN_HANDLER` を渡しません。

## 持ち主が手で開く近道

持ち主が Air で Dia などを手で開けるようにします。上の 5 つのアプリのうち、持ち主が自分の一覧に書いたものだけに専用の包みを作ります。`desktop` の包みは作りません。

専用の包みの実行ファイルは `Contents/MacOS/istesso-owner-shim` です。同じチェックアウトの `scripts/daily.sh` を子として直接起動し、終わるまで待ちます。これで Mac 側が起動元をたどれます。引数は作成時に決めた `open <アプリ名> --host mac` で、表示先は Air です。子には `DAILY_OWNER=1` と `DAILY_OPEN_HANDLER=1` を渡します。

この包みを起動できるプログラムは、持ち主と同じようにそのアプリを開けます。起動元をたどっても、持ち主が手で開いたかは分かりません。試用版ではこの危うさを受け入れます。専用の近道を開くのは持ち主だけです。エージェントが起動しないことは、作業の規約で定めます。
