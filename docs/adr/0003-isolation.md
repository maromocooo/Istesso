# ADR 0003：隔離は専用ユーザーで行う

- 状態：採用
- 日付：2026-11-15

## 背景

この仕組みで使うデータは、各 PC の普段の領域から切り離したい。とくに、コーディングエージェントに読ませる範囲を区切りたい。

ストレージの置き場所を分けるだけでは足りない。アプリやエージェントはその PC のユーザー権限で動くので、他の領域も読めてしまう。

## 決定

- 各 PC に、この仕組み専用のユーザーを作る。隔離領域はそのユーザーのホームに置く。
- この仕組みで動かすアプリと、herdr・コーディングエージェントは専用ユーザーで動かす。
- 普段使いのユーザーのホームは、他のユーザーから読めない権限にしておく。
- ツール側のサンドボックス（Claude Code の sandbox 設定、Codex の読み取り拒否設定）は二重の柵として併用する。土台は OS の権限に置く。

## 結果

- エージェントはターミナルのプロセスなので、専用ユーザーで動かすだけで区切れる。
- 専用ユーザーに渡した鍵・証明書・トークンは、そのままエージェントの手が届く範囲になる。必要最小限にする。
- Apple 向けのビルドと署名を専用ユーザーで行う場合、証明書をそのユーザーのキーチェーンに入れる必要がある。
- Mac で GUI アプリを専用ユーザーのセッションから配信する方法は M4 で検証する。
