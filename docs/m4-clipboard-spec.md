# Mac のホストの、文字のコピーと貼り付け（M4 の流れへの仕様）

- 状態：仕様（2026-11-19）。Mac のホストの流れ（`m4-daily-host`）が作る。**試用版だけ**。
- 決まりの正本：[ADR 0022](adr/0022-clipboard-text.md)（試用版で採用。持ち主の決めの 1〜6 を含む）。この文書は、そのうちの Mac のホストの部分を、作れる形に書き下したもの。食い違えば ADR が正しい。
- 相手の側（このブランチ `trial-daily-clipboard` にある）：エージェント `istesso agent --clipboard`（`crates/istesso-agent/src/clipboard.rs`、`serve.rs`）、中継、Air のビューアー。Ubuntu の側の同じもの：`m3-compositor-clipboard` の `scripts/patches/gst-wayland-display-trial-y-clipboard.patch`（`gwd-trial28`）。

## 1. 全体の流れ

```text
Air のビューアー ─(copy / paste, 入力の接続)→ 試用のエージェント（Studio、--clipboard）
                                                 │ (1) clipboard.sock へ：hello、paste_text（文字）
                                                 │ (2) input.sock へ：順番の合図（文字なし）
                                                 ▼
                                           Mac のホスト（Istesso Dev Daily Host）
                                                 │ (3) clipboard-answer.sock へ：hello、answer
                                                 ▼
                                           エージェント → 中継 → ビューアー
```

- Mac のホストが新しく持つもの：**クリップボードの口 `clipboard.sock`**（受ける）と、エージェントの**答えの口 `clipboard-answer.sock`**（送る先）。どちらも、いまの入力の口（`input.sock`。エージェントが入力のデータグラムを送ってくる口）と**同じフォルダー**に置く。
- `daily-mac.sh`：試用のエージェントに `--clipboard` を足す。ビューアーの設定に `ISTESSO_CLIPBOARD=1` を足す（Ubuntu の `daily.sh` と同じ）。エージェントは、`--clipboard` のとき、入力の口のフォルダーに `clipboard-answer.sock` を自分で開く。

## 2. 手元の口

どれも Unix のデータグラムで、中身は 1 つの JSON。

| 口 | 開く側 | 権限 | 大きさ |
|---|---|---|---|
| `<入力の口のフォルダー>/clipboard.sock` | **Mac のホスト**。起動のときに開く。前の実行が残したソケットだけを消してから（`lstat` でソケットのときだけ）開く | 0600。フォルダーは本人だけ（0700）のまま | `SO_RCVBUF` を 256 KiB に上げる。読む緩衝は 192 KiB |
| `<入力の口のフォルダー>/clipboard-answer.sock` | エージェント | 0600 | Mac のホストの送る口は、名前のない口で、`SO_SNDBUF` を 256 KiB に上げる |

- macOS のデータグラムは、既定では 2 KiB ほどしか送れない（`net.local.dgram.maxdgram`）。**両方の緩衝を上げないと、貼り付けの文字が届かない**（エージェントは自分の側を上げてある）。
- 入力の口が作り直されたら（Mac のホストの起動し直し）、`clipboard.sock` も作り直す。エージェントは、入力の口が替わると入力の接続を閉じ、つなぎ直しの `input_open` で `hello` をやり直す。

## 3. データグラム

### エージェント → `clipboard.sock`

| 中身 | Mac のホストがすること |
|---|---|
| `{"kind":"hello","nonce":"<16 進 32 字>"}` | **すぐに**、同じ中身 `{"kind":"hello","nonce":"…"}` を `clipboard-answer.sock` へ送る。エージェントは 0.3 秒待ち、返ってきたときだけ、Air に「受ける」と言う。返さなければ、Air の ⌘C と ⌘V は、ふつうのキーのままになる |
| `{"kind":"paste_text","nonce":"…","text":"…"}` | その合い言葉の文字として取っておく（2 秒で忘れる。いくつも来てよい）。**順番の合図より先に来る** |

### エージェント → `input.sock`（キーと同じ道、キーと同じ順番）

| 中身 | 意味 |
|---|---|
| `{"kind":"clipboard_copy","nonce":"…","cut":false}` | コピー（`cut:true` なら切り取り） |
| `{"kind":"clipboard_paste","nonce":"…","with_text":true}` | 貼り付け。`with_text:false` なら、文字なしの貼り付け |

- これらは `istesso_proto::InputEvent` ではない。いまの `InputEvent` を読むところで、知らない種類として捨てられないように、先に `kind` を見て分ける。

### Mac のホスト → `clipboard-answer.sock`

```json
{"kind":"answer","nonce":"…","result":"…","text":"…","why":"…"}
```

- `result`：`text`（コピーで、文字が取れた）、`pasted`（貼り付けのキーを押した）、`none`、`refused`、`too_large`、`not_text`。
- `text`：`result` が `text` のときだけ。`why`：`refused` のときだけで、`password_field`、`secret_marker`、`secure_input` のどれか。
- 1 つの合い言葉に、答えは 1 つ。2 秒より遅い答えは、エージェントが捨てる（送っても害はない）。
- エージェントは、自分が作り、まだ待っている合い言葉の答えだけを受け取る。合い言葉は、どこにも書かない。

## 4. コピー（`clipboard_copy`）

順に：

1. **押せる相手か**：いまのキーの決まりと同じ（アプリの窓の形では、そのアプリが前面で、キーの窓が範囲の中。`docs/m4-daily-host.md` の「入力が届く範囲」）。だめなら、何も押さずに `none`。
2. **パスワードの確かめ（キーを押す前に）**：
   - `IsSecureEventInputEnabled()` が真なら `refused` / `secure_input`。これは Studio 全体の状態（ターミナルの「安全なキーボード入力」、パスワードの道具）。Air の窓には、原因を分けた知らせが出る。
   - そのアプリのフォーカスのある要素（`AXFocusedUIElement`）の**サブロール**（`AXSubrole`）が `AXSecureTextField` なら `refused` / `password_field`。ロール（`AXTextField`）では分からない。読めなかったときは、押してよい（名乗らない欄と同じ扱い。ADR の「見分けられないもの」）。
3. 押す前の `NSPasteboard.generalPasteboard.changeCount` を覚える。
4. そのアプリに ⌘C（`cut` なら ⌘X）を押して離す。**修飾キーは、ホストの側の状態に合わせる**：Command が、もう押したと送ってあれば（Air の ⌘ がホストの ⌘ として届いている）、C だけを押して離す。押していなければ、Command を押し、C を押して離し、Command を離す。どれも押されたまま残らないこと。いまの、キーをそのアプリへ送る道（`CGEventPostToPid` と前面の決まり）を使う。
5. `changeCount` が変わるのを、**0.5 秒まで**待つ（10 ミリ秒おきに見る程度）。変わらなければ `none`。
6. 変わったら、**文字を読む前に**、すべての項目の種類を見る。`org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` のどれかがあれば `refused` / `secret_marker`（中身は読まない）。
7. `public.utf8-plain-text` を読む。なければ `none`。
8. 確かめる：UTF-8 で 65536 バイトを超えたら `too_large`（切り詰めない）。空、またはタブ・LF・CR のほかの制御文字（U+0000〜U+001F のうち 09、0A、0D のほか、U+007F〜U+009F）を含めば `not_text`。どれでもなければ `text` と、その文字。
9. Studio のペーストボードは、そのまま（アプリが置いたもの）。こちらからは戻さない、消さない。

- プライマリーの選択のようなものは、Mac にはない。書式（RTF、HTML）、ファイル、絵は読まない。

## 5. 貼り付け（`clipboard_paste`）

### 文字あり（`with_text: true`）

1. その合い言葉の `paste_text` が、もう来ているかを見る。**来ていなければ、来るまで、`input.sock` から来たそのあとのイベント（キー、ポインター、文字、合図）を、渡さずに順に持つ。0.2 秒まで。** 過ぎたら、貼り付けをやめて `none` と答え、持っていたものを順に渡す。⌘V のすぐあとに打ったキーが、貼り付けを追い越さないためである。
2. 文字を確かめる（4 の 8 と同じ）。だめなら、キーを押さずに `too_large` か `not_text`。
3. 押せる相手か（4 の 1 と同じ）。だめなら `none`。
4. Studio のペーストボードに置く：`prepareForNewContentsWithOptions:NSPasteboardContentsCurrentHostOnly`（Universal Clipboard で、ほかの端末へ渡さない。決め 2）、文字を `public.utf8-plain-text` で置き、**同じ項目に `org.nspasteboard.TransientType` の印を付ける**（Studio のクリップボードの道具が、履歴に取らない。決め 3。印の中身は空のデータでよい）。
5. そのアプリに ⌘V を押して離す（修飾キーは 4 の 4 と同じ）。
6. `pasted` と答え、持っていたイベントを順に渡す。
7. **Studio のペーストボードは、前の中身に戻さない**（決め 3。アプリが中身を読む時刻が分からない）。

### 文字なし（`with_text: false`）

1. Studio のペーストボードの中身が、**こちらが前の貼り付けで置いたもの**（覚えておいた `changeCount` がいまと同じ）なら、先に取り下げる（`clearContents`）。前に Air から渡した古い文字が貼られないようにするため。アプリが自分で置いたものは、そのまま。
2. ⌘V を押して離す。`pasted` と答える。

## 6. 記録に出さない

- 文字、文字の大きさ、合い言葉を、どこにも書かない（ログ、標準出力・標準エラー、時刻の記録、`--self-test` の出力）。
- 書いてよいのは数だけ：hello に答えた回数、コピーと貼り付けの回数、答えの種類ごとの回数。例：`clipboard: copy answered refused (2 so far)`。
- Rust の `Debug` で、文字を持つ型を表に出さない（`istesso_proto::SecretText` を使えば隠れる）。

## 7. Studio の Handoff の確かめ（起動の道具）

- 持ち主は、2026-11-19 に Studio の Handoff を切った（ADR 0022 の決め 6）。`daily-mac.sh`（か、Studio で窓を開く道具）は、開くたびに、**読むだけで** Handoff が切れているかを確かめ、また有効になっていたら、持ち主に 1 行で知らせる（止めはしない）。
- 読み方の候補（Studio の上で、読むだけで確かめてから決める）：`defaults -currentHost read com.apple.coreservices.useractivityd ActivityAdvertisingAllowed` と `ActivityReceivingAllowed`。**書き換えない**（設定は持ち主のもの）。読めなければ「分からない」と言う。

## 8. 許可の画面（先にまとめ役に知らせる）

- Mac のホストが Studio のペーストボードを**読む**（4 の 6〜7）と、macOS が許可を尋ねる画面を出すかもしれない（ADR 0022 の「動かして確かめること」2）。出るのは、誰もいない Studio の画面で、そのあいだ読み出しは止まるか、断られる。**読むところを動かす前に、まとめ役に知らせる。** 尋ねられたときに断られた・待たされたら、`none` と答えて、知らせを 1 行出す。
- 書くだけ（5 の 4）は、尋ねられない見込み（見ていない）。
- アクセシビリティの読み（サブロール）は、いまの許可の中（ADR 0017）。新しい許可は足さない。

## 9. 確かめ（窓なしで、先にできること）

- `--self-test` に足す：
  - hello を受けて、同じ合い言葉を返す。
  - `paste_text` が合図より遅れて来たとき、そのあいだのキーが、貼り付けのあとに順に渡る。0.2 秒を過ぎたら `none` で、キーが順に渡る。
  - 文字の確かめ（65536 バイトちょうどは通り、1 バイト多いと `too_large`。制御文字、空）。
  - 答えの形（`text` は `text` のときだけ、`why` は `refused` のときだけ）。
  - ペーストボードは、本物（`generalPasteboard`）ではなく、名前つきの自分のもの（`pasteboardWithUniqueName`）で試す。本物は、8 のとおり、知らせてから。
- エージェントと合わせた確かめ：このブランチの `crates/istesso-agent/src/serve.rs` の試験（`copy_and_paste_go_as_marks_among_the_keys_and_the_answer_comes_back` など）が、相手の振る舞いの手本になる。

## 10. 作らないもの

- AURA の窓（ADR の外）。
- 自動で合わせること。メニューの「コピー」を選んだときに運ぶこと。
- 絵、ファイル、書式。
- 製品の Mac のホスト（ペーストボードが Studio に 1 つで、ほかのセッションから読めることは、試用版だけの例外。ADR 0022 の「セッションのあいだの受け渡し」）。
