# 自前のホスト：フレームの通り道（ホストだけ。ADR 0019 の計測の 1）

- 日付：2026-11-17（17:29〜17:31。本線が走らせた）
- 測ったもの：ブランチ `m1-own-host` の自前のホスト（`istesso-host-linux`、関の見直しまでが入った版）と、計測用のスクリプト（`scripts/m1-step3-host.py`）
- 目的：自前のホストが、フレームの通り道で、スクリプトより遅くないこと（「並んだ」とする線の 1 つ目。[ADR 0019](../adr/0019-own-host.md)）。関が最後のフレームを持ち続けることが、何かを遅くしていないこと
- 結論：**どの区間も、スクリプトより悪くない。** コンポジターを出てから渡し終えるまでは、平均で 4.16 ms → 3.94 ms。圧縮は、同じ（3.89 → 3.85 ms）。短くなったのは、このプログラムのコードが通る所（関、渡すところ）である

## 条件

| 項目 | 値 |
|---|---|
| ホスト | 関門の判定と同じ PC。机には、だれもログインしていない（SSH だけ） |
| 絵 | テストアプリの動く文字、3440×1440、毎秒 85 枚、GPU で描く（`istesso-flash --picture text --fps 85 --draw gpu`） |
| 経路 | フレームは GPU の上のまま。H.265 の 4:4:4、上限 30 Mbps、キーフレームは最初だけ、確定のたびに描く、カーソルは絵の外。2 つとも、同じ引数 |
| 送り先 | なし。暗号化した経路で待ち受けるが、だれもつないでいない。入力も送っていない。Mac は使っていない |
| 切り替え | 全部「切」 |
| コンポジターのプラグイン | 同じコミットに同じ 4 つの修正を当てて、この流れのフォルダーでビルドしたもの。**関門の判定で使ったビルドとは、別のビルド**である（ソースは同じ） |
| 測り方 | 45 秒ずつ、スクリプト、自前のホストの順。フレームの記録の、始めの 5 分の 1 を除いた全部（3,073 枚と 3,074 枚） |
| ほかに動いていたもの | 持ち主の試用の窓（別のコンポジターとエンコーダー）。記録していない |

## 分かること、分からないこと

- 分かること：フレームの通り道の、ホストの中の 4 つの区間で、自前のホストは、スクリプトより遅くない。
- 分からないこと：入力の経路。見る側がつないでいるときの封と書き込み。2 台での差（中継した窓 − 手元の窓）。これらは、2,000 回ずつの 2 台での回で測る（ADR 0019 の「並んだ」とする線の残り）。
- 1 回ずつの値で、取り直していない。

## 5 つ目の修正（cursor-shape の口）を当てたプラグインと、当てていないプラグイン（2026-11-17 19:58〜19:59。本線が走らせた）

- 目的：コンポジターの 5 つ目の修正（[ADR 0009](../adr/0009-host-compositor.md) の 6）が、フレームの通り道に、何も足していないこと。
- 測り方：上と同じ条件で、自前のホスト（コミット 06dd1f7 のビルド）を、45 秒ずつ 2 回。違うのは、プラグインだけ（4 つの修正のビルドと、5 つの修正のビルド。どちらも、この流れのフォルダーでビルドしたもの）。切り替えは、全部「切」。カーソルは、絵の外（5 つのほうでは、口が開いている）。だれもつないでいない。入力は、送っていない。
- **この 2 回のあいだ、ホストでは、夜の音の試験の復号の負荷が動いていた。** だから、この 2 回は、互いにだけ比べる。上の表の値とは、比べない。

コンポジターを出てから、書き終えるまで（ms）

- 時刻の印の付け替えは、どちらも 0。関での待ちの行は、どちらも、なかった。
- **結論：5 つ目の修正は、フレームの通り道の時間を、増やしていない**（5 つのほうが、0.01〜0.03 ms 短い。1 回ずつの値で、この差に意味があるとは言えない）。
- 分からないこと：ポインターを動かしているとき（カーソルの知らせが出ているとき）の値。この 2 回では、入力を送っていない。

## 再現のしかた

ホストで、同じ引数のスクリプトと自前のホストを、だれもつながない形で 45 秒ずつ動かし、その中でテストアプリを動かす。フレームの記録の `frame_out`、`converted`、`encoded`、`sent` の時刻を、フレームごとに引く（エンコーダーが印に足す決まった値を、いちばん多い差として引いてから、突き合わせる）。走らせた手順と、区間を出す小さなスクリプトは、作業用のフォルダーにあり、リポジトリには入れていない。
