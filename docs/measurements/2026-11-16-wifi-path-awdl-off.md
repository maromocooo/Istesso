# 経路そのものの遅れ：AWDL を止めた状態（Wi-Fi）

- 日付：2026-11-16
- コミット：27b879e（コードの変更なし）
- 目的：[手順 0](2026-11-16-step0-wifi-path.md) で見つけた決まった間隔の跳ねが、Mac の AWDL を止めると消えることを確かめる。

## 条件

| 項目 | 値 |
|---|---|
| ホスト | 手順 0 と同じ。Wi-Fi は 802.11ax、信号 −72 dBm、省電力は有効 |
| クライアント | 手順 0 と同じ |
| 接続 | 2台とも Wi-Fi（6 GHz 帯のチャンネル 53）。Mac の AWDL を止め続けた |
| 解像度とフレームレート | 映像なし |

AWDL は、1回止めても macOS が約 1 分で戻します。計測のあいだ、Mac で次を実行したままにしました（人が実行）。

```sh
sudo sh -c 'while :; do ifconfig awdl0 down; sleep 1; done'
```

## 測り方

08:46:27 から 08:54:18（JST）まで、Mac からホストへ、Mac からルーターへ、同時に `ping` を 1800 回ずつ流しました。指定した間隔は 0.2 秒、実際の間隔は平均 0.26 秒です。集計は `scripts/ping-stats.py` で行いました。

AWDL の状態を 2 秒おきに調べると、228 回のうち 227 回が停止でした。カーネルのログでは、計測のあいだに AWDL が 2 回、約 1 秒ずつ戻っています（08:49:55 と 08:51:12）。

## 結果

| 経路 | AWDL | 回数 | 欠落 | 最小 | 中央値 | 95% | 99% | 最大 | 遅い応答の割合 |
|---|---|---|---|---|---|---|---|---|---|
| Mac → ホスト | あり（手順 0） | 1800 | 0 | 4.9 ms | 8.3 ms | 94.8 ms | 252.0 ms | 381.7 ms | 22.3% |
| Mac → ホスト | **止めた** | 1800 | 0 | 4.0 ms | **7.2 ms** | **16.1 ms** | **48.7 ms** | **179.9 ms** | 5.8% |
| Mac → ルーター | あり（手順 0） | 900 | 0 | 2.4 ms | 4.0 ms | 68.5 ms | 93.0 ms | 279.6 ms | 17.1% |
| Mac → ルーター | **止めた** | 1800 | 0 | 2.3 ms | **3.1 ms** | **6.9 ms** | **8.2 ms** | **144.1 ms** | 1.1% |

- 16 ms を超えた応答は、Mac → ホストで 22.6% から 5.1% に減りました。
- 遅い応答が 512 TU の周期にそろう度合いは、0.66 から 0.14 に下がりました（偶然でも 0.10 程度）。決まった間隔の跳ねは消えています。

60 ms を超えた応答は、次の 4 つの時刻に集まっていました。

| 時刻 | 出た経路 | 重なっていたこと |
|---|---|---|
| 08:49:55.9 | 両方（92 ms、87 ms） | AWDL が 08:49:55.4 から約 1 秒戻った |
| 08:51:13.4 | 両方（180 ms、144 ms） | AWDL が 08:51:12.5 から約 1 秒戻った |
| 08:47:33〜08:47:47 | Mac → ホストだけ（最大 82 ms） | ホストのスキャン（08:47:47 のログ） |
| 08:52:49〜08:52:54 | Mac → ホストだけ（最大 174 ms） | ホストのスキャン（08:52:56 のログ） |

## わかったこと

- **跳ねの原因は Mac の AWDL で確定です。** 止めると、Mac とルーターの間は 95 パーセンタイルが 68.5 ms から 6.9 ms になります。
- **止めても、2台とも Wi-Fi の経路は 95 パーセンタイルが 16.1 ms です。** 暫定の合格ライン（16 ms）を、転送だけで使い切ります。残りの遅れはホスト側にあります。ホストの信号は −72 dBm と弱く、5 分おきにスキャンが入り、遅い応答はビーコンの周期に弱くそろっています（0.36、偶然でも 0.10 程度）。
- **次の改善は、ホストを有線にすることです。** Mac とルーターの間だけなら、中央値 3.1 ms、95 パーセンタイル 6.9 ms です。
- **止め続けても、8 分のうちに 2 回、約 1 秒ずつ AWDL が戻りました。** そのたびに 100 ms を超える遅れが出ます。恒久的な対処は、AWDL を使う機能（AirDrop、ユニバーサルコントロールなど）を設定で切るか、Mac を有線にするかです。どれにするかは、1つずつ試して測ってから決めます。
