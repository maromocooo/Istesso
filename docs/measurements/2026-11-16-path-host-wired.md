# 経路そのものの遅れ：ホストを有線にしたあと

- 日付：2026-11-16
- コミット：19c210b（コードの変更なし）
- 目的：ホストを有線にしたので、経路の計測をやり直す（[README.md](README.md) の「経路そのものの遅れ」）。ホスト側の電波区間がなくなったことを確かめる。

## 条件

| 項目 | 値 |
|---|---|
| ホスト | Ubuntu 24.04。有線（2.5 Gbps）。Wi-Fi も有効なままで、同じネットワークに 2 つのアドレスを持つ |
| クライアント | MacBook Air（M4）、macOS 26.5.1。Wi-Fi（6 GHz 帯、802.11ax） |
| 接続 | Mac は Wi-Fi、ホストは有線。計測は有線側のアドレスに向けた |
| 解像度とフレームレート | 映像なし |

ホストに 2 つのアドレスがあるので、有線側のアドレスへの通信が実際にケーブルを通ることを、計測の前後に確かめました。Mac から見たそのアドレスのハードウェアアドレスが、ホストの有線のアダプターと一致することを見ています。

## 測り方

Mac からホスト（有線側のアドレス）へ、Mac からルーターへ、同時に `ping` を流しました。指定した間隔は 0.2 秒、実際の間隔は平均 0.27 秒です。

| 回 | AWDL | 時刻（JST） | 回数 |
|---|---|---|---|
| 1 | 有効のまま | 10:26:36〜10:30:35 | 900 回ずつ |
| 2 | 止め続けた（[方法](2026-11-16-wifi-path-awdl-off.md)） | 10:37:17〜10:42:35 | 1200 回ずつ |

2回目のあいだ、AWDL は 2 回、1 秒未満だけ戻りました（10:39:02 と 10:39:20）。

## 結果

| 回 | 経路 | 回数 | 欠落 | 最小 | 中央値 | 95% | 99% | 最大 |
|---|---|---|---|---|---|---|---|---|
| 2 | Mac → ホスト（有線）、AWDL 停止 | 1200 | 0 | 2.0 ms | **3.3 ms** | **7.1 ms** | **9.7 ms** | 324.6 ms |
| 2 | Mac → ルーター、AWDL 停止 | 1200 | 0 | 2.3 ms | 3.1 ms | 7.1 ms | 10.8 ms | 318.8 ms |
| 1 | Mac → ホスト（有線）、AWDL あり | 900 | 0 | 2.4 ms | 4.1 ms | 71.8 ms | 108.1 ms | 386.1 ms |
| 1 | Mac → ルーター、AWDL あり | 900 | 0 | 2.3 ms | 4.1 ms | 73.7 ms | 109.9 ms | 412.7 ms |

これまでの値と並べると、次のとおりです（Mac → ホスト）。

| ホスト | AWDL | 中央値 | 95% | 99% |
|---|---|---|---|---|
| Wi-Fi | あり | 8.3 ms | 94.8 ms | 252.0 ms |
| Wi-Fi | 停止 | 7.2 ms | 16.1 ms | 48.7 ms |
| 有線 | あり | 4.1 ms | 71.8 ms | 108.1 ms |
| **有線** | **停止** | **3.3 ms** | **7.1 ms** | **9.7 ms** |

2回目で 16 ms を超えた応答は 0.4% で、すべて 10:39:36 からの 5 秒間に集まっていました（59〜325 ms、4 回）。ルーターへの経路にも同じ時刻に出ています。同じ時刻に、Mac の Wi-Fi のドライバーがローミングの設定を切り替えたことがログにあります。これが原因とみていますが、確かめていません。

## わかったこと

- **ホストを有線にすると、ホストまでの往復は、ルーターまでの往復と同じになります。** 差は中央値で 0.1 ms です。ホスト側の電波区間と、5 分おきのスキャンの影響はなくなりました。
- **ホストが有線で、Mac の AWDL が止まっていれば、経路の 95 パーセンタイルは 7.1 ms です。** 手順 0 の 94.8 ms から、ここまで下がりました。
- **残りは Mac 側の Wi-Fi です。** AWDL が動いていれば、ホストが有線でも 95 パーセンタイルは 72 ms のままです。AWDL を止めても、5 分に 1 回程度、数秒の停止がありました。Mac も有線にすれば、この区間もなくなります。
