# 手順 1：計測の道具を2台で動かす

- 日付：2026-11-16
- コミット：この記録と同じコミット（道具を足したコミット）
- 目的：テストアプリと記録の仕組みが2台で動くことを確かめ、テストアプリ自身の応答時間を知る。映像はまだ通していない。

## 条件

| 項目 | 値 |
|---|---|
| ホスト | Ubuntu 24.04、RTX 4090。テストアプリは X11 のデスクトップに表示（窓の中身は 960×600 画素）。リリースビルド |
| クライアント | MacBook Air（M4）、macOS 26.5.1。リリースビルド。Mac の中だけの計測では、窓の中身は 1920×1200 画素（960×600 ポイント） |
| 接続 | 2台とも Wi-Fi（6 GHz 帯）。経路の遅れは [手順 0 の記録](2026-11-16-step0-wifi-path.md) のとおりで、AWDL は止めていない |
| 解像度とフレームレート | 映像なし |
| 経路 | 合成の入力（UDP、暗号化なし）と、その返事 |

## 結果

`istesso measure inputs` で測りました。入力の間隔は 200〜400 ms、乱数の種は 20261116 です。どの回も欠落はありません。

| 回 | 指標 | 回数 | 中央値 | 95% | 99% | 最大 |
|---|---|---|---|---|---|---|
| 1. Mac → Ubuntu（Wi-Fi 越し） | 転送（往復） | 500 | 8.33 ms | 91.04 ms | 225.89 ms | 331.34 ms |
| | アプリの応答（Ubuntu） | 500 | 0.52 ms | 1.00 ms | 1.12 ms | 3.12 ms |
| 2. Mac の中だけ。エージェントのシェルから起動 | 転送（往復） | 500 | 0.25 ms | 0.50 ms | 0.81 ms | 9.10 ms |
| | アプリの応答（Mac） | 500 | 4.69 ms | 7.17 ms | 8.95 ms | 27.37 ms |
| 3. Mac の中だけ。`open` で起動 | 転送（往復） | 150 | 0.25 ms | 0.60 ms | 0.91 ms | 1.04 ms |
| | アプリの応答（Mac） | 150 | 4.59 ms | 5.27 ms | 5.55 ms | 5.83 ms |

追加遅延と、その内訳（取り込みと圧縮、復号、表示待ち）は、映像を通していないので測っていません。

参考：入力の間隔を 20〜40 ms に詰めると、Mac でのアプリの応答は中央値 1.41 ms でした（200 回、エージェントのシェルから起動）。

## わかったこと

- 道具は2台で動きます。Wi-Fi 越しの転送（中央値 8.3 ms、95 パーセンタイル 91.0 ms）は、手順 0 の `ping`（中央値 8.3 ms、95 パーセンタイル 94.8 ms）と合っています。
- Ubuntu でのテストアプリの応答時間は、中央値 0.5 ms、最大 3.1 ms です。追加遅延から引く値として、小さく、そろっています。
- **Mac でのテストアプリの応答時間は中央値 4.6 ms で、Ubuntu の約 9 倍です。** macOS では、色を変えるたびに窓の全画素（約 9 MB）を確保し直して塗る実装（softbuffer）になっています。入力の間隔を詰めると 1.4 ms まで縮むので、間が空いたあとの書き込みが遅いと見ていますが、確かめていません。当てるテスト（手順 5）では手元の窓がこの分だけ遅くなり、中継した窓に有利に働きます。手順 5 までに、macOS では窓の背景色を変えるだけの描き方に変える予定です。
- **エージェントのシェルから起動したプログラムは、優先度が低い状態で動きます**（`ps -M` の PRI が 20。`open` で起動すると 47）。2 と 3 を比べると、中央値は変わりませんが、最大が 27.4 ms から 5.8 ms に縮みました。手順 0 で `ping` の送信間隔が伸びたのも、これが原因と見ています。クライアント側で時刻を測るプログラムは `open` で起動します（[README.md](README.md)）。

まだ確かめていないこと：

- キーとマウスのボタンでの切り替え。人が実機で押して確かめます。
- Wayland での動作。ホストに Wayland のコンポジターがまだないので、仮想コンポジターを入れる手順 3 で確かめます。（追記：同じ日に、仮想コンポジターの中で動くことを確かめました。応答時間は中央値 0.7 ms でした。）
- 色の見え方。手元の窓と中継した窓で同じ灰色に見えるかは、映像が通ってから比べます。
