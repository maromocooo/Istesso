## 2. 直す文（【提案】）

### 2.1 同じ名前のプロジェクト（1.1）

- 1.1 は「2 台目に登録させない」。W1 の試作は、2 台が別々に登録できる（つながっていないときもある）ので、止めずに「?」を付け、開くときに `<機械>:<名前>` で選ばせる（ADR 0007 の「プロジェクトの名前で開く」）。
- 【提案】1.1 を、**「同じ名前は、2 台目に登録するときに知らせる（止めない）。開くときに、どちらかを選ばせる。当て推量で開かない」**に直す。わけ：登録の時に、ほかの機械が答えているとは限らない。
- 【問い 作19】同じ名前を 2 台に許すか。おすすめ：**許して、印を付ける**（試作の形）。

### 2.2 頼むのは ID か、名前か（1.1）

- 1.1 の「ID だけ」のわけは、「フォルダーの場所を、頼む側から受け取らない」である。名前も、受け側の登録から引くので、このわけは満たす（場所は運ばない）。
- 【提案】1.1 を、**「ほかの機械から頼めるのは、受け側の一覧にあるもの（ID か名前）だけ。場所は運ばない」**に直す。シェルのパスの形は、シェルが開いたあとどこへでも cd できるので、守りの境目ではない、と 2.3 に 1 文足す（[adr-0007.md](adr-0007.md) の A3）。
- マウントの ID（`--mount-folder`）も、同じ一覧の名前にする（A3 の【問い】）。

### 2.3 マウントと cd（1.5、2.5）

2.5 の「試作の報告」のあとに、`proto-ish-mount` の報告を足す（文は ADR 0007 の「ish とマウント」の要約）：

- cd で `~/Istesso/<機械>/<ID>/…` に入ると、その前にマウントし、マウントができてから相手のシェルになる。マウントは 1 つの場所に 1 つ（ロック）。
- **外すのは、手元で何も使っていないとき**：相手のシェルが終わったとき、と 30 秒おき。どちらも力ずくでない unmount で、使っていれば残す。**わけ**：必ず外すと、Mac のエディターが読んでいるファイルを足元から抜く。ずっと付けると、手元だけの NFS のポートが長く開く（【問い 作13】の穴）。
- 新しく要るもの（sudo、ダイアログ、許可）は、ない（試作・実機）。
- 限り：きっかけは、プロンプトで打った cd だけ。読み終えて閉じたファイルは「使っている」に数えない（30 秒のうちに外れうる）。

### 2.4 メインのエディター（3.1）

試作と 3.1 の違いを、3.1 に書く（どちらにするかは、W2b で決める）。

| こと | 3.1（設計） | 試作（`proto-main-editor`） |
|---|---|---|
| 入口のコマンド | `istesso open <ファイル>[:<行>]` | `istesso-edit <ファイル>` |
| 頼みが運ぶもの | プロジェクトの ID、相対の場所、行 | 開発の機械の中の口（`open.sock`）に、`file <絶対の場所>`。機械の外へは、場所を運ばない |
| エディターの決め方 | アプリの一覧の ID | エージェントの起動の引数 |
| 確かめ | 名前 1 つずつ、リンクをたどらない | 同じ（`openat` に `O_NOFOLLOW`、`O_DIRECTORY`） |

- 【提案】入口の名前は **`istesso open` にそろえる**（URL を開く頼みと同じ口、同じ名前。`istesso-edit` は試作の名前として残す）。頼みの中身は、開発の機械の中では絶対の場所でよい（機械の外へ出ないため）、と 3.1 に書く。
- 朝のまとめの【問い】（金曜のあと）：起動の係が、自分の古い起動のフォルダーを消してよいか。→ [adr-0007.md](adr-0007.md) の A8。

- 4.8 の「ほかのユーザー」：**【決定】（2026-11-20、持ち主）ブラウザーの機械のほかのユーザーからの接続は、断る。** 作り方は ADR 0007（Linux は接続の uid、macOS はプロセスの一覧）。試作には、まだない。
- 4.9 に足す：シェルを終えても、そのシェルから始めて端末を離れたサーバーは、残る（試作の確かめで、1 時間ほど、全部のネットワークで待ち受けたまま残った。資料：ADR 0007 の転送の節「見つけたこと」）。ADR 0007 の【問い】（シェルが終わったとき、作業場に残ったサーバーをどうするか）を、【問い 作10】に結ぶ。決定 8（権利を取り消しても herdr とエージェントは止めない）との釣り合いを、そこで書く。
