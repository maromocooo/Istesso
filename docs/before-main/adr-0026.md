## 2. 足す文（【提案】）

### 2.1 「守らせる仕組み」に足す：Landlock の TCP の決まりの、抜け道

> **Landlock の「つなぐ」の決まり（版 7）は、`connect` の呼び出しにだけ効く。** TCP Fast Open（`sendto` などに `MSG_FASTOPEN`）と、MPTCP のソケットは、断られたポートにも、つながった〔実〕。`io_uring` は、監督の係を通らずに、開き、つなぎ、送れる〔推〕。`open_by_handle_at` は、場所なしで開く〔推〕。
>
> だから、段 (1)〜(3) の起動の係は、Landlock に加えて、seccomp で次を断る：`sendto`、`sendmsg`、`sendmmsg` の `MSG_FASTOPEN`（`EOPNOTSUPP`）、`socket` の `IPPROTO_MPTCP`（`EPROTONOSUPPORT`）、`io_uring_setup`、`io_uring_enter`、`io_uring_register`、`open_by_handle_at`（`ENOSYS`）。監督の係のない形でも、同じ決まりだけは掛ける〔実：直したあと、どちらの形でも断られた〕。
>
> `TCP_FASTOPEN_CONNECT` を立ててからの `connect` は、Landlock が断った。つないでいない TCP のソケットへの、宛先つきの `sendto`（Fast Open なし）は `EPIPE` だった〔実〕。
>
> **これは、この試作だけでなく、Landlock でポートを絞る形の全部に当たる。** 新しいカーネルの版（10 以降）で、どう扱われるかは、調べていない。SCTP、UDP、生のソケットなど、TCP でない道は、版 7 では止まらない（nftables の決まりが要る。【問い 範11】）。

「守りの強さの違い」の表の「ネットワークを、決まった宛先だけにする」の Linux の列にも、1 文：「Landlock のポートの決まりは、`connect` だけ。seccomp で Fast Open と MPTCP と io_uring を断って、はじめて、ポートの決まりになる」。

「試作のあと」の「中継のポートのほかへの TCP は、断られた」は、**「`connect` では、断られた（Fast Open と MPTCP は、seccomp で断るまで、通った）」**に直す。

### 2.2 5 章「範囲の外で止まったとき」に足す：試作の形

> 試作（`proto-agent-scope`、Linux）では、範囲の外の `open`、`openat`、`creat`、`connect` を、seccomp のユーザー通知で止め、問いを、頼んだ端末へ、Istesso の道で送る。答えは 4 つ：**今回だけ**、**この回のあいだ広げる**、**広げて覚える**、**断る**。30 秒答えがなければ、断る〔実〕。
>
> - 境目は、いつも Landlock。許したものは、監督の係が、**自分で写した中身で**行う（リンクをたどらない `openat2`、または止めたソケットでの `connect`）。止めたプロセスが、あとから書き換えた場所は使わない〔実：競り合いの試し〕。
> - 「広げて覚える」は、覚えのファイルに書く。ファイルは、次の起動で Landlock の決まりになる。宛先は、監督の係が持つ。覚えのファイルの行は、**1 バイトも変えずに戻るか、まるごと断る**（行の終わりの CR を、前は黙って落としていた。5a77545 で直した）。
> - 問いの窓には、双方向の制御文字、幅のない文字、見えない文字を、印に置き換えて出す。そういう字を含む場所は、問わずに断る（5a77545）。

【提案】5 章の「答えは 3 つ」を「答えは 4 つ（広げるは、この回のあいだ／覚える）」に直すかは、【問い 範5】（どこまでを「今回」とするか）と一緒に決める。

### 2.3 【問い 範14】に足す

> **試作のあと（2026-11-20 の朝）：** ファイルと `connect` を止めて聞く形で、Air から 6 回通し、最後の 3 回は 32 の確かめが全部通った（08:11、最後のコード）。競り合いの試し（別のスレッドが、開くあいだに場所を書き換える）：全部を断ったとき、外のファイルは 55,739 回のうち 0 回、片方だけ許したとき、もう 1 つの外のファイルは 29,952 回のうち 0 回、読まれた〔実〕。大きなビルドでの遅れは、まだ。
