# Istesso で、ホストの音を Mac で聞く（1 ページの使い方）

2026-11-17 の時点の、開発中の形です。**音が聞こえる形で始めるのは、持ち主が「始めてよい」と言ってからです。** それまでは、無音で数えるだけの形で動かします。

## 何が Mac に届くか

始めると、ホストの出力先の一覧に **「Istesso (to the Mac)」** という出力先が 1 つ増えます。**その出力先に流した音だけ**が、Mac に届きます。ホストのスピーカーやヘッドホンに流している音は、届きません。始めただけでは、ホストの既定の出力は変わらず、どのアプリの音も、これまでどおりに鳴ります。

**ホストで、持ち主が選ぶこと：** 聞きたい音の出力先を、「Istesso (to the Mac)」にします。ホストの「設定」›「サウンド」›「出力」で選ぶと、ホストのすべての音が Mac に行き、ホストのスピーカーからは鳴らなくなります。元に戻すには、同じところで、元の出力先を選び直します。止めると、この出力先は一覧から消え、ホストは、元の出力先に戻ります。こちらのスクリプトは、ホストの設定を変えません。

## 始める・止める

Mac のターミナルで、リポジトリのフォルダーから。

| すること | 打つもの |
|---|---|
| 始める（無音。数えるだけ） | `scripts/istesso-audio.sh start` |
| 始める（**音が聞こえる**） | `scripts/istesso-audio.sh start --audible` |
| 止める（Mac とホストの両方） | `scripts/istesso-audio.sh stop` |
| 様子を見る | `scripts/istesso-audio.sh status` |

- 音の大きさは、Mac の音量で決まります。はじめて聞くときは、Mac の音量を小さくしてから始めてください。
- 始めるには、Mac からホストへのログイン（ssh）が開いている必要があります。開いていなければ、「ホストに届かない」と出ます。
- 接続が切れたときは、自分でつなぎ直します（切れてから 5 秒のあいだは 0.1 秒おきに、そのあとは 0.25 秒おきに試す）。ホストを再起動したときは、もう一度、始めてください。

## 用意（1 回だけ）

Mac の `~/.config/istesso/audio.env` に、次の項目を書きます（このファイルは、リポジトリには入れません）。

| 項目 | 中身 |
|---|---|
| `HOST_SSH` | ホストへの ssh の別名 |
| `SOURCE_ADDR` | ホストの、有線 LAN のアドレス |
| `HOST_PROGRAM`、`HOST_CONFIG` | ホストの `istesso` のプログラムと、その鍵のフォルダー（`'~/…'` のように、引用符で囲む） |
| `EXIT_CONFIG` | Mac の鍵のフォルダー |
| `PEER` | ホストの、ペアリングの名前（省ける） |
| `VIA` | `shell`（いまは、これだけ）。署名したアプリができたら `app` にして、`EXIT_APP` にアプリの場所を書く |
| `EXIT_PROGRAM` | `VIA=shell` のときの、Mac の `istesso` のプログラム |
| `WAIT_MS` | 待ち時間（省くと 60） |

## 記録と、気づいたことの知らせ方

動いているあいだ、1 時間ごとと 1 日ごとに、まとめが 1 行ずつ残ります。止めたときにも、そこまでの分が残ります。

- Mac：`~/.local/state/istesso/audio/exit.jsonl`（並べて動かす基準のプレーヤーは `reference.jsonl`）
- ホスト：`~/.local/state/istesso/audio/source.jsonl`

1 行には、いつからいつまで、クリック（ホストの取り込みが逃した周期）、飛ばし、途切れの回数と長さ、つなぎ直し、機器の組み替え、いちばん長い無音、遅れ、音が聞こえる形だったかどうか、が入ります。名前、アドレス、何を鳴らしたかは、入りません。

聞いていて、プツッという音、音の飛び、途切れ、遅れに気づいたら、**時刻**（分まで）と、何が起きたかを、知らせてください。記録の行と突き合わせます。

## いまの制限

- **Mac の再生は、ターミナルから起動する形です。** Mac がほかの作業で忙しいと、音が飛びやすくなります。アプリとして起動する形（飛びが出なかった形）は、署名したアプリができてからです。
- **ヘッドホンをつないだり外したりしても、音は、始めたときの出力先に出続けます。** 出力先を替えたいときは、止めて、始め直してください（付いていくようにする作業を、進めています）。
- 今日の状態では、1 時間に 3 回ほど（2〜13 回）、プツッという音が出る見込みです。
- ペアリングは、テスト用の鍵です。ホストのプログラムは、この日の版に作り直してから使います。
