# Seguito security policy

## Supported versions

Seguito is in pre-release development. We accept security reports about the current pre-release code and its proposed designs.

## Report a vulnerability privately

Use GitHub’s private reporting form for this repository. You can also find it under **Security** → **Report a vulnerability**. Please keep the details out of public issues and pull requests. [Report a vulnerability privately](https://github.com/maromocooo/seguito/security/advisories/new)

Please include the following details and omit pairing codes, keys, tokens and personal information.

- Identify the affected commit or the document revision and section you reviewed.
- Describe what access the problem requires and what someone could read, change or control.
- For an implementation issue, describe what you expected and what you observed. For a design issue, explain which assumption fails.

## What to expect

We will acknowledge your report within a few days and discuss it with you privately. We will keep the vulnerability private until a fix is available, then coordinate disclosure with you. We will credit you in the disclosure if you wish.

## Security reviews

Seguito has undergone AI reviews. No one outside the project has reviewed its security yet.
